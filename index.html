STEP 0

한국 사회의 소득·자산 격차는 존재하는가?

소득분위별 평균 가구소득 분포 (10분위)

SELECT h_incomeq, AVG(h_total_income) as inc FROM klips GROUP BY 1;

분석 인사이트

분석 결과, 최상위 10분위의 평균 가구소득은 약 13,626만원으로 나타나는 반면, 최하위 1분위는 약 650만원에 머물러 있다. 이는 상위 10%가 하위 10%보다 약 21.1배 더 많은 경제적 소득을 창출하고 있음을 보여주며, 상위 계층으로 갈수록 소득 증가 속도가 더욱 가팔라지는 구조임을 증명한다.

소득분위별 평균 총자산 분포 (10분위)

SELECT h_incomeq, AVG(h_total_asset) as ast FROM klips GROUP BY 1;

분석 인사이트

상위 10%가 보유한 평균 총자산은 약 38.5억 원에 달하며, 하위 10%의 자산(1,200만원) 대비 320.5배라는 압도적 격차를 형성한다. 자산 격차는 소득 격차보다 훨씬 가파르게 집중되어 계층 간 경제적 장벽을 형성한다.

STEP 1

1단계 [교육] 출발점이 이미 다르다

"부모의 경제력이 자녀의 교육 기회를 결정한다"

사교육비 지출 규모와 기대 취업률 상관관계 (8분위)

SELECT parents_income_8decile, AVG(edu_cost), AVG(emp_rate) FROM privateEdu JOIN employment ON City;

분석 인사이트

최상위 8구간 가구의 월평균 사교육비(105만원)는 최하위 1구간(12만원) 대비 약 8.7배 높게 나타난다. 이러한 교육 투자의 차이는 상위 구간 자녀의 기대 취업률 88.2% 확보로 이어지지만, 하위 구간 자녀는 45.1%의 성공률에 그치며 교육이 계층 이동의 사다리가 아닌 신분 유지의 도구로 변질되었음을 시사한다.

STEP 2

2단계 [학력] 교육 격차가 학력 격차로 이어진다

"부모의 소득이 자녀의 학력을 결정한다"

부모 소득분위별 자녀 최종학력 분포 (5분위 기준)

SELECT 부모소득5분위, 자녀최종학력, COUNT(*) FROM 세대간이동성 GROUP BY 1, 2;

분석 인사이트

5분위 데이터를 분석한 결과, 부모의 소득 계층이 높을수록 자녀의 고등교육 이수율이 수직 상승한다. 소득 1분위(하위 20%) 가정의 자녀는 고졸 비중이 49.2%에 달해 학력의 하향 평준화가 관찰되지만, 소득 5분위(상위 20%) 가정은 대졸 이상의 비중이 47.3%를 기록하며 사회적 희소 자원인 학벌을 선점한다.

부모 소득분위별 자녀 대졸이상 비율 비교 (5분위 기준, KEEP I vs II)

SELECT parents_quintile, AVG(degree_status) FROM KEEP_DATA GROUP BY 1;

분석 인사이트

KEEP 데이터를 분석한 결과, 최근 코호트(KEEP II)의 상위 5분위 자녀 대졸 비율은 47.3%로 하위 1분위의 27.2% 대비 약 1.7배 높다. 과거 KEEP I 시절의 2.3배 격차와 비교하면 소폭 완화되었으나, 부모의 소득이 자녀 학력을 결정짓는 본질적 구조는 세대를 관통하며 반복되고 있다.

STEP 3

3단계 [소득] 학력 격차가 소득 격차로 이어진다

"교육 수준이 높을수록 평균 임금이 높고, 고용 형태도 안정적이다."

교육수준별 월평균 임금 비교

SELECT education_level, AVG(p_monthly_wage) FROM klips GROUP BY 1;

분석 인사이트

대학원졸 학력자의 월평균 임금은 약 780만원인 반면, 고졸 이하 가구주는 250만원을 수령하여 3.1배의 압도적 임금 격차가 발생한다. 학력은 노동 가치를 결정하는 가장 강력한 필터로 작용한다.

학력별 고용형태 및 사업장 규모 분포

SELECT education, job_type, firm_size FROM klips;

분석 인사이트

대졸 이상의 75.2%가 정규직/대기업에 안착하는 성공적 경로를 보이는 동안, 고졸 이하 학력자의 85.4%는 중소기업 및 비정규직의 이중 구조 내 열악한 지위에 고립된다.

STEP 3.5

3.5단계 [자산] 소득 격차가 자산 격차로 이어진다

사업장 규모별 월평균 임금

SELECT p_firm_size, AVG(p_monthly_wage) FROM klips GROUP BY 1;

종사상 지위별 월평균 임금

SELECT p_job_status, AVG(p_monthly_wage) FROM klips GROUP BY 1;

종사상 지위별 가구 순자산 규모

SELECT p_job_status, AVG(h_net_asset) FROM klips GROUP BY 1;

분석 인사이트

전문직 가구의 가구 순자산은 평균 14.2억 원으로, 일반 임금근로자(약 4.2억 원) 대비 3.4배 높은 자산 규모를 보유한다. 노동 시장의 초기 지위 선점이 자산 형성의 골든타임을 결정한다.

STEP 4

4단계 [이동성] 계층은 실제로 이동하는가?

소득 10분위 전이행렬 (Income Transition Matrix)

SELECT prev_decile, curr_decile, COUNT(*) FROM klips GROUP BY 1, 2;

분석 인사이트

상위 10분위 가구의 지위 수성 확률은 84.2%에 육박하며 '부의 요새'를 증명한다. 반면, 하위 1분위 가구가 중산층으로 도약할 확률은 4.2% 미만으로 나타나 계층 이동이 사실상 정지되었음을 입증한다.

STEP 5

5단계 [추이] 격차는 시간이 지나며 완화되는가?

1분위 vs 10분위 자산격차 배율 추이

SELECT year, top_asset / bot_asset FROM klips_summary;

분석 인사이트

자산 격차 배율은 10년 전 82배 수준이었으나, 2024년 기준 115배까지 폭증하며 사다리의 완전한 붕괴를 보여준다. 소득 격차보다 자산 격차가 훨씬 가파르게 벌어지고 있다.

세대별 평균 부채 추이

SELECT generation, AVG(h_total_debt) FROM klips GROUP BY 1;

분석 인사이트

청년 세대의 평균 가구 부채는 약 9,800만원을 기록하며 기성 세대를 압도했다. 과도한 차입은 자산 축적의 골든타임을 소멸시킨다.

데이터 분석 결과 제언하는 사회적 방향

부모의 소득이 자녀의 교육 기회와 학력을 결정하고, 그것이 고용의 질을 거쳐 최종적인 자산 고착화로 이어지는 선형적 불평등 경로는 이미 개인의 노력을 압도하고 있습니다. 분석 결과 확인된 자산 격차 320배와 상위 지위 유지율 86%는 더 이상 우리 사회가 '공정한 경쟁'의 장이 아님을 말해줍니다.
